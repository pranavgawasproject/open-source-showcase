# open-source-showcase

A live, auto-updating dashboard of my open source repositories — pulled straight from the GitHub API. No build step, no stale cache.

**Live demo:** https://pranavgawasproject.github.io/open-source-showcase/

## Screenshots

![Open Source Showcase dashboard](docs/screenshot-home.jpg)

## Features

- Terminal-inspired UI for browsing public repos
- Live data from the GitHub API (search, sort, include forks)
- Static GitHub Pages host — no backend

## Tech

HTML · CSS · vanilla JS · GitHub REST API · GitHub Pages

## Setup

Open `index.html` locally, or push to `main` and enable GitHub Pages.
